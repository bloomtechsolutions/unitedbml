# Structure Tab Redesign

Changes:
- Rebuilt the Structure tab into a visual org-chart style layout.
- Added support for displaying user photos/avatars.
- If a user photo URL is available on the selected member record, it is shown.
- If no photo exists, initials are displayed in a styled avatar circle.
- Each structure node now shows:
  - role
  - group
  - photo/avatar
  - member name
  - email
  - status badges
  - quick actions
- Added legend and improved visual hierarchy for a more interactive look.

# Final Approval Email Update

The final approval email now includes:
- Request details
- Event/activity
- Request date and category
- Prepared by
- Purpose/justification
- Full expense line table
- Quantity, rate and line totals
- Reimbursement flag
- Subtotal
- 5% contingency
- Total requested
- Budget overrun information where relevant
- President recommendation and comments
- Secure approval link
- Open-in-UnitedBML link

The PDF is not attached to this email, which reduces Supabase Edge Function CPU/memory usage. The President-stage PDF remains available from the secure approval page.

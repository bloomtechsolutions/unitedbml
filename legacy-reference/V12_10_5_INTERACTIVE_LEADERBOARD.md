# UnitedBML V12.10.5 Interactive Leaderboard

The engagement scoring rules are unchanged.

## New experience
- interactive Top 3 podium
- staff initials avatars
- Overall / Events / Tournaments / Delivery views
- search by staff / UID
- Department filter when Staff Master information is available
- engagement summary strip
- contribution progress bars
- expandable staff profiles
- event / tournament / task / achievement breakdown
- Starter / Bronze / Silver / Gold engagement levels
- mobile-responsive ranking layout

## Existing scoring retained
- Event participation / attendance: +3
- Completed Event task: +2
- Approved Tournament participation: +3
- Tournament achievement: +5
- Tournament winner / first place: +10

No SQL migration is required.

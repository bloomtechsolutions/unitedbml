# UnitedBML V12.9.8 Outlook Desktop Email

The grouped Procurement email is now built for Outlook Desktop compatibility.

Changes:
- fixed 680px centered email width
- nested presentation tables
- explicit HTML width attributes
- inline styles only
- MSO conditional wrapper for classic Outlook
- no flexbox, grid, border-radius dependency or web-layout CSS
- cleaner Expense Request / Event summary
- compact Expense Items table
- clear Total Amount row
- boxed reimbursement reason
- conditional MVR10,000 advisory box
- compact attachment panel
- signed-in UnitedBML user signature

The grouped Procurement approval and line-wise reimbursement/AP logic are unchanged.

No SQL migration is required.

# UnitedBML Rebrand

This build changes the application-facing brand from ClubSphere to **UnitedBML** and uses the supplied UnitedBML logo.

Updated areas include:
- Browser title and favicon
- Sign-in screen
- Sidebar logo and application name
- Dashboard title
- Approval pages
- Finance/reimbursement emails
- PDF/report footers and report titles
- User-facing authentication/sync messages

Technical database table names, Supabase schema, internal DOM IDs, and selected IndexedDB/cache identifiers were intentionally retained to avoid breaking existing data or integrations.

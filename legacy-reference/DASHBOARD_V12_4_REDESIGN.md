# UnitedBML Dashboard V12.4

The dashboard was rebuilt to be compact, corporate and action-oriented.

## Executive Dashboard
- compact six-item status strip
- 7-day / 30-day agenda instead of a large month calendar
- priority work and approval exceptions
- notification center
- recent activity
- engagement & delivery indicators
- finance and approvals snapshot
- operational pulse including events, meetings, reimbursements and tournaments

## My Dashboard
The same dashboard switches into a user-specific view:
- assigned events/tasks only
- personal approvals and reimbursement items
- personal agenda
- personal notifications
- My Events / My Meetings / My Tournaments / My Requests shortcuts

## Notifications
Notifications are assembled from current operational state:
- pending finance approvals
- overdue / due-soon tasks
- upcoming events
- tournament updates

Unread state is stored locally per browser for the compact notification center.
The top-header bell opens the dashboard notification panel and shows the unread count.

## Design
- reduced card sizes
- tighter spacing
- agenda-first navigation
- contextual actions
- responsive two-column desktop layout
- mobile-friendly collapse
- UnitedBML navy/purple corporate visual language

No database migration is required for the dashboard redesign.
